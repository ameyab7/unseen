# Chip

Pill-shaped toggles for picking nights, times and report reasons.

Each chip is a real button with `aria-pressed`, at least `touch-target` tall. Off: `seam-strong` border and `pearl` label. On: `lamplight` fill and `lamplight-ink` label. A group has a visible label tied to it with `aria-labelledby`. Use chips for several short choices; anything longer than three words becomes a list of buttons.

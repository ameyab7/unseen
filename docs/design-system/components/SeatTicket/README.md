# Seat ticket

The seat card, cut as a ticket: which night, what time, and what happens next.

`plush` with `radius-l` corners and two 12px notches at mid-height. States: requested (the nights asked for, and when casting happens), cast (the night and time, with a Confirm button), confirmed (a `success` line with a check icon and when backstage opens) and standby. It never names or hints at the other dater before the date. The consumer provides the state and times.

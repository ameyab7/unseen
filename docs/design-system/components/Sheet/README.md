# Sheet

A bottom sheet for short decisions and small forms, shown over `scrim`.

`plush-raised` with `radius-l` top corners and a grab handle. It takes focus when it opens, closes on Escape or a tap on the scrim, and returns focus to whatever opened it. Only one sheet shows at a time; a sheet that leads to another replaces it. The title states the decision ("Leave this date?"), and the option that keeps things as they are sits last, nearest the thumb, as a quiet button.

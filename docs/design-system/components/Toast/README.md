# Toast

A short confirmation at the top of the screen that clears itself after about three seconds.

`pearl` with `velvet` text, the inverse of the page, on `radius-m` corners with a check icon and `role="status"`. It says what just happened in the past tense and, when it matters, what happens next: "Seat released, no strike." Never use a toast for an error that needs action, or for anything about money the person must read; those belong on the screen or in a sheet.

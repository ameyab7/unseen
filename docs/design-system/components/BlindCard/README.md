# Blind card

Everything listeners and a date know about a dater before any reveal.

First name and age in `display-name`, pronouns if given, a 15-second voice intro with a play button, and two prompt answers. The verified line states exactly what was checked: real person, 18+, face matches ID. It never says "safe" and never implies a background check. No photo, last name, workplace or neighborhood, ever. The consumer provides the dater's chosen name, which can differ from their ID.

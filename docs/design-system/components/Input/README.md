# Input

A labelled text field with helper text, used for the blind card, questions to Nova and chat.

The label sits above the field (15px semibold, `pearl`); a placeholder never stands in for a label. The field is `control-height` tall with a `plush` fill, a 1.5px `seam-strong` border and `radius-m` corners. Focus adds the 2px `focus` ring. Errors switch the border and helper text to `danger`, add an icon, and say what to fix. Fields that are read on air (name, prompts) warn as people type if they include a last name, workplace or address. The consumer provides the label, helper text and validation.

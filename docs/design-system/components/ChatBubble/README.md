# Chat bubble

Messages between two people after a mutual reveal, plus notes from Nova.

Theirs sit on the left in `plush`. Yours sit on the right in `lamplight` with `lamplight-ink` text. Nova's note is centered, outlined and labelled "Nova" in `nova`; it appears once, to open the chat with a callback from the date. Timestamps say "Sent", never "Read": read receipts add pressure without helping anyone reply. Message text is `body` (17px) and never smaller.

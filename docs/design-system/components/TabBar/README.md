# Tab bar

The app's three destinations: Tonight, Dates and You.

Labels always show; icons never stand alone. The current tab is `pearl` with a filled icon and `aria-current="page"`; the others are `mist` with outline icons. It hides on full-screen moments (the live room, backstage, the decision, the reveal) and inside a chat. When someone minimizes the live room, a mini-player sits just above it so the show keeps playing. The icons in the preview stand in for Phosphor's broadcast, ticket and user icons.

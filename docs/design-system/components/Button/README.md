# Button

Pill-shaped actions in four variants: primary, secondary, quiet and destructive.

- Primary (`lamplight` fill, `lamplight-ink` label): one per screen, for the action the screen exists for, such as Listen in or I'm ready.
- Secondary (`seam-strong` outline, `pearl` label): the safe alternative, such as Not tonight.
- Quiet (`lamplight-text`): low-stakes links such as How the show works.
- Destructive (`danger` outline and label, with an icon): Report, Block, Delete account.

On consent screens, both choices use the same variant, size and width, so neither reads as the default. Height is `control-height` (44px in compact rows), full width on phones, with a 17px semibold label in sentence case, verb first. Don't disable a button to hide an option; explain what's needed instead.

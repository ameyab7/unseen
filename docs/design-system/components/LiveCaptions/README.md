# Live captions

Captions for the live room, drawn from the same real-time transcript moderation already uses.

Each line carries its speaker: daters in `mist`, Nova as "Nova (AI)" in `nova`. Text is `caption-live` (20px). Anything moderation removes, such as a street or a workplace, shows as a dashed "removed" tag instead of the words, matching the muted audio. Captions are on by default for listeners, and daters can switch them on for their own date. The panel is a log that screen readers can browse without live announcements, so a date never talks over itself.

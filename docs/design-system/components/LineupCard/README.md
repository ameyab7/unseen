# Lineup card

The on-air card on Tonight: who is on, how long is left, and one way in.

It shows the on-air lamp, the date's place in the running order, the listener count, both daters as initial discs with the speaking ring on whoever is talking, their names in `display-name`, a waveform, the time left and "hosted by Nova (AI)". One primary button: Listen in. Off air, the same card becomes the countdown; between dates, it shows who is up next. It never shows photos, last names or anything the daters didn't put on their blind cards.
